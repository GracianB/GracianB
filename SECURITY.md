# Security

This is a static public portfolio site.

## Reporting

Please do not publish sensitive information, credentials, tokens or private data in issues.

For a security concern involving the site or repository, contact the repository owner through [GitHub](https://github.com/GracianB) or the email published on the portfolio.

## Scope

The site does not intentionally expose secrets or server-side credentials. External services and third-party links are treated as public dependencies and should be reviewed before introducing new ones.
