## About this repository

This is the source for my public profile hub and its companion application pages. It is a static site: HTML, CSS, and JavaScript, with no application backend. GitHub Pages serves the site from the repository root.

| Path | Purpose |
| --- | --- |
| `index.html`, `main.js`, `i18n.js` | Main hub, interactions, and English/Spanish content |
| `styles.css`, `*-v*.css` | Site styling and responsive visual systems |
| `apply.html`, `apply.js`, `apply.css` | Application desk and role-specific summaries |
| `cabin-*.html`, `cabin-*.css`, `cabin-*.js` | Cabin-crew portfolio and application pages |
| `docs/` | Portfolio artwork and visual assets |
| `scripts/` | Static checks and browser-test tooling |
| `.github/workflows/` | Continuous integration and publishing workflows |
| `Gracian_Baena_*.pdf` | Canonical public application documents |

### Run locally

From the repository root, start a static web server:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). No build step or backend is required for the static pages.
