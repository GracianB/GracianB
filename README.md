## I didn't start with code. I started with people.

Over 16 years across customer service, retail leadership, international B2B SaaS, Customer Success and operations taught me something: **most business problems don't need another slide deck. They need a system that works.**

I worked with people and teams before I built tools for them. The code came later, when I got tired of stopping at recommendations.

I connect business context, data, automation and software to make difficult processes simpler, measurable and useful. I like results you can open, inspect and challenge.

> **Proof before promise.** No imaginary metrics. No borrowed products. If something is public, you can try it.

## How this portfolio works

A deliberately lightweight stack: **HTML · CSS · JavaScript · GitHub Pages**. Dark petrol for the technical hub, graphite and silver for the professional CV, and distinct identities for each world.

Automated checks cover browser behavior, accessibility-sensitive navigation, language/theme continuity, resource budgets and responsive layouts. Lighthouse-style scores and career outcomes aren't invented.

The development history lives in [the pull requests](https://github.com/GracianB/GracianB/pulls) and the [release notes](./RELEASE_P1_FINAL.md), not in a 30-page README.
