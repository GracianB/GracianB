# 🧠 MI FORMA DE TRABAJAR

No empiezo por la herramienta.

## Empiezo por el problema.

```text
PROBLEM
   │
   ▼
CONTEXT
   │
   ▼
SIGNAL
   │
   ▼
CRITERIA
   │
   ▼
SYSTEM
   │
   ▼
ADOPTION
   │
   ▼
OUTCOME
```

Mi método puede resumirse en cuatro movimientos:

### 01 · ESCUCHAR

Entender qué está pasando realmente.

### 02 · DECIDIR

Separar señal de ruido y convertir información en criterio.

### 03 · CONSTRUIR

Crear el sistema, automatización, análisis o herramienta que resuelva el problema.

### 04 · ACTIVAR

Conseguir que aquello que se ha construido sea realmente utilizado.

> **Un sistema que nadie utiliza es solamente una pieza de ingeniería con autoestima.**

# 🧠 HOW I WORK

I do not start with the tool.

## I start with the problem.

```text
PROBLEM
   │
   ▼
CONTEXT
   │
   ▼
SIGNAL
   │
   ▼
CRITERIA
   │
   ▼
SYSTEM
   │
   ▼
ADOPTION
   │
   ▼
OUTCOME
```

My method can be reduced to four movements:

### 01 · LISTEN

Understand what is actually happening.

### 02 · DECIDE

Separate signal from noise and turn information into criteria.

### 03 · BUILD

Create the system, automation, analysis or tool that solves the problem.

### 04 · ACTIVATE

Make sure what was built is actually used.

> **A system nobody uses is just engineering with an inflated sense of self-importance.**
