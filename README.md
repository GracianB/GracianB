## Design system

The hub is deliberately built as a lightweight static site rather than a framework-heavy application.

- **HTML / CSS / JavaScript**
- **GitHub Pages**
- **ES / EN i18n**
- **Dark / light theme**
- Responsive layout
- Keyboard-friendly navigation
- Reduced-motion support
- Command palette
- Semantic metadata and Schema.org
- Open Graph / Twitter cards
- Sitemap and robots directives
- Accessible focus states
- No build step required

### Visual language

**Fraunces · Inter · JetBrains Mono**

Warm black, champagne, ice-neon and sage connect the three worlds while giving each one its own role.
